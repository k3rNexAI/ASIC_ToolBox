# Дизайн-направление

## Тема: Control room graphite
Интерфейс внутреннего инструмента для инженеров дата-центра: тёмный графитовый фон, тёплый янтарный акцент как сигнал мощности и прохладный циан для сети.

- **Принцип:** сначала состояние и действие, затем детали.
- **Сетка:** левый узкий rail-навигация + контентная область с карточками.
- **Цвета:** graphite #0c1117, panel #141b24, cyan #47d7e8, amber #ffb84d, red #ff6b6b, muted #8d9aaa.
- **Типографика:** Inter/system sans для UI; моноширинный шрифт для IP, моделей и числовых показателей.
- **Интеракции:** короткие переходы, явные состояния loading/success/warning, никаких скрытых действий.
- **Голос:** спокойный, технический, на русском.
- **Signature:** amber status dot и компактные chips 1/3, 2/3, 3/3.
