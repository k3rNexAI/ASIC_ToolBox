# ASIC Mix Control — эксплуатация и обслуживание

## 1. Перенос на Windows

1. Распакуйте архив в папку пользователя, например `Документы\\asic-mix`.
2. Не меняйте структуру папок `runtime` и `tools`.
3. Запустите `run-windows.cmd`.
4. Откройте `http://127.0.0.1:4180`.
5. Оставьте окно консоли открытым.
6. Для остановки закройте окно консоли.

Права администратора не нужны.

## 2. Portable-компоненты

В комплект входят:

- `runtime\\node.exe` — portable Node.js;
- `tools\\grpcurl.exe` — portable grpcurl;
- файлы проекта — JavaScript, HTML и CSS.

Никакой установки npm-зависимостей для запуска Windows-комплекта не требуется.

## 3. Данные

Единственный постоянный файл приложения:

```text
state.json
```

Он хранит только список ЦОДов. Результаты сканирования хранятся в памяти текущей страницы и исчезают после перезапуска.

## 4. Резервная копия

Перед изменениями или переносом сохраните:

```text
state.json
```

Также полезно сохранить весь каталог проекта, чтобы не потерять portable runtime и grpcurl.

## 5. Смена порта

Если `4180` занят:

1. Откройте `run-windows.cmd`.
2. Измените:

```bat
set "PORT=4181"
```

3. Сохраните файл.
4. Запустите лаунчер снова.
5. Откройте `http://127.0.0.1:4181`.

## 6. Смена пароля ASIC

В `run-windows.cmd`:

```bat
set "ASIC_USER=root"
set "ASIC_PASSWORD=новый_пароль"
```

Пароль не записывается в `state.json` и не выводится в интерфейс.

## 7. Принтер TT-200

Печать выполняется браузером:

1. Нажмите **«Печать результата группы»**.
2. Откроется окно предпросмотра.
3. Браузер автоматически откроет стандартный диалог печати.
4. Выберите TT-200.
5. Проверьте размер рулона/этикетки в настройках драйвера.

Приложение задаёт ширину этикетки `58 mm`. Фактические поля, скорость и термопечать зависят от драйвера TT-200.

## 8. Если печать заблокирована

Проверьте:

- разрешены ли всплывающие окна для `127.0.0.1`;
- установлен ли драйвер TT-200;
- выбран ли правильный размер бумаги;
- не открыто ли окно печати за другим окном;
- не блокирует ли корпоративная политика печать из браузера.

## 9. Если приложение не запускается

Проверьте:

```bat
runtime\\node.exe --version
```

Если команда не запускается:

- проверьте антивирус;
- скопируйте папку из сетевого диска в локальные «Документы»;
- проверьте, что файл не помечен Windows как загруженный из интернета;
- попросите IT разрешить конкретный portable executable.

## 10. Если ASIC offline

Проверьте порты:

```powershell
Test-NetConnection <IP> -Port 4028
Test-NetConnection <IP> -Port 50051
```

Если доступен только 50051, приложение должно использовать gRPC fallback.

В интерфейсе можно включить только `gRPC 50051`, только `TCP 4028` или оба. Если включены оба, TCP используется только после ошибки gRPC для конкретного ASIC. Для обычного быстрого скана оставляйте включённым только gRPC.

## 11. Безопасность

- не запускайте приложение с `HOST=0.0.0.0` без необходимости;
- не передавайте архив с паролем ASIC посторонним;
- не коммитьте `run-windows.cmd` с реальным паролем в публичный репозиторий;
- не размещайте приложение за публичным reverse proxy без аутентификации;
- при необходимости внешнего доступа добавьте TLS, авторизацию и журналирование.

## 12. Проверка перед передачей новой версии

```bash
npm run check
unzip -t asic-mix-windows-portable.zip
```

Нужно убедиться, что архив содержит:

- `server.js`;
- `public/index.html`;
- `public/app.js`;
- `public/styles.css`;
- `runtime/node.exe`;
- `tools/grpcurl.exe`;
- `run-windows.cmd`.


## Резервное копирование (1.1.0)

1. Откройте `http://127.0.0.1:4180/api/backup/export` в браузере на том же ПК.
2. Сохраните полученный JSON на диск, отличный от каталога приложения, например на разрешённый корпоративный сетевой диск.
3. Повторяйте экспорт после изменений карт ЦОДов и после важных расчётов микса.
4. Для восстановления сначала остановите приложение, затем скопируйте текущий каталог целиком в отдельное место. Не импортируйте JSON вручную поверх рабочей папки без проверки структуры.
5. Автоматическое восстановление из экспортированного файла пока не реализовано.

Локальные файлы `state.json.bak` и `maps.json.bak` содержат предыдущую версию соответствующего файла. Они не заменяют независимую резервную копию каталога.
