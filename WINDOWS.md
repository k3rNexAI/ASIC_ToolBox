# Windows: запуск одним EXE без прав администратора

Для новой однофайловой сборки скопируйте только `ASIC ToolBox.exe` на компьютер и запустите его. Node.js и файлы рядом с EXE не нужны. Исходники, интерфейс и `grpcurl.exe` встроены в исполняемый файл; изменяемые данные хранятся в `%LOCALAPPDATA%\ASIC ToolBox`. Инструкция по сборке и миграции данных приведена в [WINDOWS_EXE.md](WINDOWS_EXE.md).

## Старый portable-вариант на основе папки

Папка уже содержит portable Node.js (`runtime\node.exe`), поэтому устанавливать Node.js, открывать PowerShell от администратора, создавать службу Windows или менять реестр не требуется.

1. Скопируйте всю папку `asic-mix` на доменный ПК — например, в `Документы`, на рабочий стол или на доступный сетевой диск.
2. Дважды кликните `run-windows.cmd`.
3. Через несколько секунд браузер откроет `http://127.0.0.1:4180`.
4. Окно консоли оставьте открытым во время работы. Для остановки закройте его.

Сервер слушает только `127.0.0.1`, то есть интерфейс не публикуется в сеть и не требует правила Windows Firewall. Сам сканер при этом подключается из-под этого ПК к ASIC по TCP 4028, а если Braiins OS не отвечает на legacy API — по gRPC TCP 50051. Для gRPC fallback в папке `tools` уже есть portable `grpcurl.exe`.

## Если устройства показываются как OFFLINE

На проблемном ПК откройте PowerShell без прав администратора и выполните для одного ASIC:

```powershell
Test-NetConnection 10.0.12.41 -Port 4028
Test-NetConnection 10.0.12.41 -Port 50051
```

Если `50051` показывает `TcpTestSucceeded : True`, а `4028` — `False`, это штатный случай для Public API: обновлённый сканер должен использовать fallback на 50051. Если оба порта `False`, проблема находится между этим ПК и ASIC: VLAN, маршрут, ACL или Windows/сетевой firewall. Если `50051` доступен, но результат всё равно OFFLINE, наведите курсор на статус — в подсказке будут видны ошибки обоих API.

В таблице офлайн-устройства скрыты по умолчанию. Чтобы увидеть их IP-адреса и ошибки подключения, включите переключатель **«Показывать офлайн»**.

## Если браузер не открылся

Откройте вручную `http://127.0.0.1:4180`. Если порт занят, перед запуском можно изменить строку `set "PORT=4180"` в `run-windows.cmd`, например на `4181`.

## Где сохраняются данные

Список ЦОДов сохраняется в файл `state.json` рядом с лаунчером. Папка должна быть доступна пользователю на запись. Никаких данных в реестр или системные каталоги приложение не записывает.

## Антивирус и доменные ограничения

Некоторые корпоративные политики блокируют запуск `.cmd` или неизвестных `.exe` с сетевого диска. В таком случае скопируйте папку в локальные «Документы» пользователя и попросите IT разрешить конкретный файл `runtime\node.exe`; права локального администратора для самого приложения не нужны.
